# Сайт Анны Вейт

Сайт-визитка дизайнера карточек для Wildberries, Ozon и Яндекс Маркета: https://annaveit.ru

## Как менять сайт

Админка: **https://admin.annaveit.ru**. Вход по почте и паролю, затем код из Google Authenticator.

Разделы:
- **Работы** — лента на главной;
- **До и после** — ползунок;
- **Отзывы** — раздел появится на сайте с первым отзывом;
- **Статьи** — блог;
- **Цены**, **Обо мне**, **Вопросы**, **Контакты**.

Нажали «Сохранить» — через 1–2 минуты изменение на сайте. Ошиблись — на главной админки есть кнопка «Отменить
последнее изменение».

## Для разработчика

- `npm run dev` — локальный сервер. `npm run build` — сборка: замки `check-content` (дата статьи ГГГГ-ММ-ДД) и
  `check-prices` (цена только в `src/data/prices.json`), свежие посты канала, сборка Astro.
- Контент — файлы: `src/content/{works,cases,posts,reviews}`, `src/data/*.json`. Их пишет админка
  (`/root/anna-admin`, свой коммит на каждое «Сохранить»), поля сверяет её сторож `tests/test_schema_parity.py`.
- Выкладка: GitHub Actions → Pages на каждый push в `main` и раз в шесть часов (блок «Свежее в канале»). GitHub
  выключает расписание после 60 дней без изменений в репозитории — тогда включить на вкладке Actions.
- Домен: переменные репозитория `SITE_URL=https://annaveit.ru`, `SITE_BASE=/`; свой домен — в настройках Pages (файл
  `CNAME` не нужен). DNS — Cloudflare, только DNS, без прокси: корень — A/AAAA GitHub Pages, `www` — CNAME на
  `djbunnyster.github.io`, `admin` — туннель Cloudflare к серверу админки. Почты на домене нет: SPF `-all`, DMARC
  `reject`, пустой MX.
- Яндекс Метрика 114088892 включается только после согласия посетителя (`src/components/Consent.astro`).
- Ключ IndexNow — файл `public/<ключ>.txt`, его же знает админка: о новой статье или работе она сообщает Яндексу сама.
